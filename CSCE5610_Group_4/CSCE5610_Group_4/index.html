Replacement Decision Flow

FIFO Replacement Policy

Maintain pages in insertion order. On a hit, keep arrival order unchanged. When frames are full, evict the oldest resident page.

VICTIM = OLDEST LOADED PAGE

LRU Replacement Policy

Maintain pages in recent-access order. A hit refreshes recency. On a fault with full memory, evict the least recently used page.

VICTIM = LEAST RECENTLY ACCESSED PAGE

07 / PROJECT DESIGN

Research Objective and Development Plan

Objective

Develop a virtual memory simulator that implements and compares First-In, First-Out and Least Recently Used page replacement algorithms under identical workloads and physical-memory constraints.

Research Question

How do FIFO and LRU differ in page-fault and page-hit performance across different reference strings and memory-frame configurations?

Experimental Method

Process fixed and user-defined reference strings with 3, 4 and 5 frames. Track memory states, page hits, faults, hit ratios, fault rates and replacement decisions.

Implementation Note

This standalone webpage uses JavaScript for the interactive simulation. The submitted proposal specifies Python 3 as the planned core implementation. A Python implementation should also be included in the final repository to follow that plan.
